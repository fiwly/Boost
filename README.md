# Aniimo Performance Booster
Xiaomi Pad 7 / Aniimo / no root.

Uses Android Game Mode controls through Shizuku. It can select FPS and per-app render scaling, set Performance mode, launch Aniimo, and display Android thermal status.

It does not overclock the Snapdragon, disable thermal protection, modify game files, or bypass anti-cheat.

Builds automatically with GitHub Actions.
